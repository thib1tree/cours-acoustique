# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : nous voulons un espace accueillant, où l'on discute de physique avec rigueur
et bienveillance. Les désaccords scientifiques sont bienvenus ; on critique des
arguments, jamais des personnes. Le harcèlement, les propos discriminatoires et les
attaques personnelles ne sont pas tolérés.

Pour signaler un comportement inacceptable, écrivez au mainteneur à l'adresse indiquée
sur son profil GitHub (thib1tree). Les signalements sont traités de façon confidentielle.
